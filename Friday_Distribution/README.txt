FRIDAY AI ASSISTANT
==================

START
-----
Double-click Start_Friday.bat to launch the Friday HUD.

REQUIREMENTS
------------
- Windows
- Python 3.12 recommended
- Required Python packages installed
- Ollama installed and running
- The qwen3:1.7b model available in Ollama

MODEL SETUP
-----------
Run: ollama pull qwen3:1.7b

SAFETY
------
This folder contains copies of the project files.
Your original project remains separate.
The original memory, notes, and logs were not copied.
Review any self-upgrade proposal before approving it.

PORTABILITY
-----------
This is a source-code distribution, not a standalone EXE.
A different PC may require Python packages and Ollama setup.
