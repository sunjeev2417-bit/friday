# FRIDAY AI ASSISTANT

An advanced personal AI assistant built with Python and local Ollama.

## Features

- Local AI using Ollama
- Qwen3 language model
- AI conversation system
- Long-term memory
- Voice assistant
- Computer vision and hand gesture detection
- System monitoring and PC controls
- Application and website launching
- Self-upgrade proposal engine
- Backup and rollback protection
- PyQt6 futuristic HUD

## Requirements

- Windows 10/11
- Python 3.12
- Ollama
- qwen3:1.7b

## Installation

1. Install Python 3.12.
2. Install Ollama.
3. Download the model:

   ollama pull qwen3:1.7b

4. Install required Python packages.
5. Run Start Friday.bat.

## Project Structure

- friday_core.py - AI core
- friday_config.py - Configuration
- friday_tools.py - System tools
- friday_memory.py - Memory
- friday_voice.py - Voice
- friday_vision.py - Vision
- friday_reel_hud.py - User interface
- friday_evolution_engine.py - Safe upgrade engine
- friday_self_upgrade.py - Upgrade generator

## Safety

Friday uses local Ollama.
Review self-upgrade proposals before applying them.
Original files are protected through backup and rollback.
